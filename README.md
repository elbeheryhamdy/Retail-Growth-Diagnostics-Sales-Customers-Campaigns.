# Retail Growth Diagnostics: Sales, Customers & Campaigns

## Project Idea
An end-to-end automated Business Intelligence and Analytics solution built on the **dunnhumby - The Complete Journey** dataset. The project establishes an automated pipeline starting with data extraction and cleaning via Python, storing and structuring relational data in SQL, feeding a dynamic Power BI system for stakeholder insights, and integrating a Predictive Machine Learning model for advanced forecasting.

## Work Plan
1. **Data Ingestion & Python Cleaning:** Complete automated data cleaning and preprocessing using Python.
2. **SQL Database Automation:** Connecting Python to SQL to automatically transfer cleaned data into structured relational tables and workflows.
3. **Power BI & Business Intelligence:** Building comprehensive dashboards and BI reports to deliver actionable insights to stakeholders.
4. **Predictive Modeling:** Developing and integrating a machine learning model for future forecasting.

---

## KPIs (Key Performance Indicators)
- **Time-Series & Growth:** WoW (Week-over-Week), MoM (Month-over-Month), QoQ (Quarter-over-Quarter), YoY Growth, and Active Household MoM Growth.
- **Profitability & Pricing:** Gross Sales, Discount Rate, Coupon Cost %, Category Discount Rate, and Promo ROI.
- **Customer Behavior:** Average Order Value (AOV), Purchase Frequency, Retention Rate, Churn Rate, Repeat Purchase Rate, Customer Lifetime Value (CLV), and Revenue Concentration.
- **Campaigns & Promotions:** Redemption Rate, Campaign Lift %, Incremental Revenue per Campaign, and Cost per Redemption.
- **Product Dynamics:** Private Label Share, Category Contribution %, and Sales per Store.
- *...and several other advanced operational and strategic KPIs.*
